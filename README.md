# ➕ Addition Game

An interactive addition game developed using HTML, CSS, and JavaScript.  
This project generates simple addition problems where users can enter answers and check whether their responses are correct.

## ✨ Features

- Random addition questions 🔢
- Instant answer checking ⚡
- Restart game functionality 🔄
- Interactive and engaging UI 🎮
- Responsive design 📱
- Beginner-friendly JavaScript project 💻

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
